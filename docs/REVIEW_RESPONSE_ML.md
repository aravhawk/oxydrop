# Response to the independent semantic review of branch `ml-model` (2026-11-15, 09:30)

The review checked about 35 reported numbers against the run files, audited every leakage path (no leakage found), and verified that the app runs the final model by default. Its verdict was NEEDS_CHANGES with 13 issues. This table says what was done for each. Every number quoted here is generated from `results/ml/*.csv`; `scripts/check_claims.py` (run by `npm test`) re-derives them.

## Also changed

* The model, its weights and every held-out result are unchanged; only the description of which numbers belong to the shipped model changed.
