All datasets are public except OpenOximetry, which is credentialed (used as derived aggregates only, never redistributed). Model weights trained on a restricted-licence dataset must be flagged here: **MTHS is CC BY-NC-ND (non-commercial research use only, no adaptations redistributed)** and **OpenOximetry is under the PhysioNet data use agreement**. The logistic chain weights (`app/data/weights.json`) are fit on Hoffman only. The shipped CNN weights (`app/data/hybrid_R_s0.json`, `hybrid_R_s1.json`, `hybrid_R_s2.json`, `app/data/oxynet.onnx`; hashes in `results/ml/FINAL_MODEL.json`) are fit on Hoffman, MTHS, BUT PPG and OpenOximetry rows plus pretraining on PhysioNet PTT-PPG, moshekam exercise, apnoea and BIDMC signals (corpus manifest: `results/ml/ssl_manifest.json`). No identifiable patient records were redistributed. The model does not train on, and the app does not store, any data from its users: camera frames are averaged in the browser and discarded. The optional "Download raw trace CSV" and "Copy debug summary" buttons write a file or clipboard text on the user's own device only.

**Compute handling.** Heavy training used a Daytona sandbox; OpenOximetry-derived arrays were uploaded only there (never to Kaggle) and stay on the sandbox and the analysis host (remove the sandbox with `python scripts/ml_daytona.py down`). Kaggle was used only for the HealthRing experiment, which touched public-licence data (HealthRing CC BY, Hoffman MIT) and no OpenOximetry or MTHS data. Checkpoints and run directories stay outside git.

## Shipped model weights: caveat for the owner to confirm

The three CNN seed files and the ONNX export are **derived models**. They were trained on MTHS (CC BY-NC-ND 4.0) and on OpenOximetry (PhysioNet credentialed data use agreement), besides Hoffman (MIT), BUT PPG (CC BY 4.0) and the PhysioNet pretraining corpus. The weights contain no raw signal, no frame and no per-person record, and the repository publishes aggregates only for OpenOximetry.

* **MTHS NoDerivatives.** Whether a neural network trained on MTHS counts as an "adaptation" under CC BY-NC-ND is not settled and has **not been cleared with the dataset's authors**. The project is non-commercial research, which the NonCommercial term allows. This is a flag, not a legal finding.
* **OpenOximetry data use agreement.** The agreement restricts redistribution of the data. Whether publishing weights trained on it is permitted must be confirmed against the agreement text and, if needed, with the PhysioNet data owners.
* **Action for the owner (Arav) before the pull request or any public release:** confirm both points, or retrain the shipped members without MTHS or OpenOximetry (a loss in skill is expected: the OpenOximetry warm-up is the largest single source of the CNN's skill, see `MODEL.md`).
